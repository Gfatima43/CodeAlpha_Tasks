# CodeAlpha Python Programming Internship

This repository contains my completed projects from the **CodeAlpha Python Programming Internship**. The internship provided practical experience in Python programming and scripting, with a focus on developing problem-solving skills through hands-on projects. The assigned tasks helped me strengthen my understanding of Python fundamentals, data structures, control flow, functions, file handling, and application development. CodeAlpha's internship program also introduces technologies such as Pandas, NumPy, Flask, and other Python tools through practical development work.

During this internship, I completed three Python projects covering different programming concepts and practical use cases.

## Projects Completed

### 1. Hangman Game

The Hangman Game is a simple text-based word guessing game developed using Python. The application selects a word from a predefined list and allows the player to guess the word one letter at a time. The game includes a limit of six incorrect guesses and provides feedback based on the player's input.

This project helped me practice Python concepts including the `random` module, strings, lists, `while` loops, and `if-else` conditions. It also improved my understanding of game flow, user input, validation, and maintaining the state of a simple application. The project follows the scope defined in the CodeAlpha internship task, which specifies five predefined words and a maximum of six incorrect guesses.

### 2. Stock Portfolio Tracker

The Stock Portfolio Tracker is a Python application designed to calculate the total investment value of selected stocks. The project uses manually defined stock prices stored in a Python dictionary. Users can enter stock names and quantities, after which the application calculates the investment value based on the stock price and quantity.

This project provided practical experience with dictionaries, user input, arithmetic operations, validation, and file handling. The project also includes investment result saving functionality, demonstrating how Python can be used to work with stored data and generate useful output. The task specification defines the use of a hardcoded stock-price dictionary and allows the result to be saved in a `.txt` or `.csv` file.

### 3. Basic Chatbot

The Basic Chatbot is a rule-based chatbot developed with Python and Flask. It provides a web-based interface where users can enter messages and receive predefined responses. The chatbot recognizes common inputs such as greetings, questions about how it is doing, and goodbye messages.

This project combines Python programming with web application development. The chatbot logic uses `if-elif-else` conditions, functions, loops, input/output handling, and predefined responses. Flask is used to connect the Python backend with the web interface, providing practical experience in building a simple Python web application.
